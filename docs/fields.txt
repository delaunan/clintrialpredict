# ClinTrialPredict: Streamlit UI Field Mapping

This document lists all fields intended for the Streamlit UI, categorized by their role in simulation, audit, and predictive intelligence.

---

### Category 1: Controllable Protocol Levers (UI Inputs)
These fields represent the controllable elements of a trial protocol. In "Simulation Mode," users can toggle these to see the impact on the Clinical Success Score.

| Field Name | UI Variable | Use Case | Logic / Importance |
| :--- | :--- | :--- | :--- |
| **Phase** | `phase` | Input | Choice: Phase 2, Phase 2/3, or Phase 3. |
| **Enrollment Target** | `enrollment` | Input | Crucial for "Scale Risk." (Continuous slider). |
| **Number of Arms** | `number_of_arms` | Input | Defines structural complexity (1 to 10+). |
| **Planned Duration** | `duration_months` | Input | Operational horizon (Log-scaled in model). |
| **Healthy Volunteers**| `healthy_volunteers`| Input | Toggle (Yes/No). Drives the `is_sick_only` feature. |
| **Blinding/Masking** | `masking` | Input | Dropdown: Double, Single, None. (Drives Design Rigor). |
| **Allocation** | `allocation` | Input | Dropdown: Randomized vs. Non-Randomized. |
| **Primary Purpose** | `primary_purpose` | Input | Dropdown: Treatment, Prevention, Diagnostic, etc. |
| **Intervention Model** | `intervention_model` | Input | Dropdown: Parallel, Crossover, Single Group. |
| **Number of Sites** | `number_of_facilities`| Input | Reflects logistical breadth. |
| **Oversight (DMC)** | `has_dmc` | Input | Toggle. Presence of Data Monitoring Committee. |

---

### Category 2: Derived Clinical Intelligence (Diagnostic Info)
These are inferred via NLP/Regex from the protocol text. In "Audit Mode," they explain the model's risk assessment. In "Simulation Mode," these could be auto-detected from user text.

| Field Name | UI Variable | Use Case | Logic / Importance |
| :--- | :--- | :--- | :--- |
| **Patient Acuity** | `is_acute` | Info / Toggle | Inferred from text: Emergency/ICU settings. |
| **Treatment Resistance**| `is_refractory`| Info / Toggle | Inferred from text: Patients who failed prior lines. |
| **Disease Burden** | `is_severe` | Info / Toggle | Inferred from text: Advanced/Metastatic stages. |
| **Sick Only** | `is_sick_only`| Info | Derived: 1 if Healthy Volunteers = No. |
| **Design Rigor Index** | `design_rigor_score`| Info | Calculated sum of Masking + Allocation + Model. |
| **Eligibility Rigor** | `eligibility_strictness_score`| Info | Calculated from Age/Gender/Sick flags. |
| **Criteria Complexity**| `criteria_len_log`| Info | Derived from character count of the criteria. |
| **Scientific Essence** | `txt_scientific_essence`| Info | The BioBERT-ready blob (Title + Summary). |

---

### Category 3: Medical & Competitive Context (Inputs/Info)
Defines the competitive and therapeutic landscape of the trial.

| Field Name | UI Variable | Use Case | Logic / Importance |
| :--- | :--- | :--- | :--- |
| **Therapeutic Area** | `therapeutic_area`| Input | The "Pillar 1" anchor (e.g., Oncology, Neurology). |
| **Medical Indication** | `therapeutic_subgroup_name`| Input | The specific niche (Target Encoded in model). |
| **Agent Category** | `agent_category` | Info | e.g., JAK_INHIBITOR, MAB, SMALL_MOLECULE. |
| **Market Heat (Broad)**| `competition_broad`| Info | Density of trials in the TA over the last 2 years. |
| **Market Heat (Niche)**| `competition_niche`| Info | Density of trials in that specific indication. |

---

### Category 4: Organizational Metadata (Audit Info)
Institutional context providing the "Who" and "When" of the trial.

| Field Name | UI Variable | Use Case | Logic / Importance |
| :--- | :--- | :--- | :--- |
| **Lead Sponsor** | `lead_sponsor` | Info | Standardized name of the primary organization. |
| **Sponsor Tier** | `sponsor_tier` | Info | Tier 1 (Giant) vs Tier 2 (Other). |
| **Agency Class** | `agency_class` | Info | Industry, NIH, or Other. |
| **Geography** | `includes_us` | Info | Binary: Does the trial have US sites? |
| **Start Year** | `start_year` | Info | Used for recency-weighting and temporal context. |
| **Enrollment Type** | `enrollment_type` | Info | Actual vs Estimated (The Transparency Flag). |

---

### Category 5: Results, Reliability & Explainability
The final model outputs and data quality markers.

| Field Name | UI Variable | Use Case | Logic / Importance |
| :--- | :--- | :--- | :--- |
| **Clinical Score** | `Clinical_Score`| Result | The final 0-100 success probability. |
| **Confidence Zone** | `Zone` | Result | Robust, Good, Watchlist, High Risk. |
| **Fidelity Label** | `prediction_quality`| Result | High, Medium, or Low (based on missingness). |
| **Success Drivers** | `shap_values` | Result | Populates the Treemap and Pillar Bar charts. |
| **Audit Narrative** | `ui_summary` | Narrative| Cleaned, date-free brief summary. |
| **Eligibility Narrative**| `ui_criteria` | Narrative| Cleaned inclusion/exclusion criteria. |
